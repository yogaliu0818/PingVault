# PingVault Privacy Policy

Last updated: 2026-11-22

## Data collection

PingVault does not collect, sell, or transmit personal data, game account data, passwords, or usage analytics to a remote service.

PingVault may read local system information required to display CPU, memory, disk, temperature, network speed, latency, and running-process status. These values are used locally by the application.

## Local data

User preferences, exclusions, session recovery information, and diagnostic logs may be stored locally on the user's computer. The user can remove these files by uninstalling PingVault or deleting its local data directory.

## Network activity

Network requests are made only when required by a user-requested feature, such as ICMP latency measurement. PingVault does not operate a VPN, proxy, remote control channel, or telemetry service.

GitHub and SignPath may process source code, build artifacts, and build metadata as part of the public release and code-signing workflow. These services are separate from the installed PingVault application.

## Third-party software

FPS integration with RivaTuner Statistics Server (RTSS) is optional. RTSS is a separate application with its own privacy policy and terms.

## Contact

For privacy questions, open an issue in the [PingVault GitHub repository](https://github.com/yogaliu0818/PingVault/issues).
